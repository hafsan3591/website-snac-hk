# SNAC ANIME — Hindi Dubbed Anime Website

একটি সম্পূর্ণ static Anime Discovery & Catalog ওয়েবসাইট। HTML, CSS, Vanilla JS। কোনো backend বা paid API নেই।

## Features
- Modern Premium Dark UI (Neon Red + Purple)
- Trending ও Latest Anime সেকশন
- শক্তিশালী সার্চ ও জেনার/ভাষা ফিল্টার
- Anime Details Modal
- মোবাইল Responsive + Mobile Menu
- Telegram বাটন (প্রতি Anime-এ আলাদা লিংক সাপোর্ট)
- Custom 404, Privacy, Disclaimer, About পেজ
- SEO meta, Open Graph
- Skeleton/Placeholder poster (কপিরাইট-সেফ)
